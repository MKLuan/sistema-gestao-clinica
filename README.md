# 🏥 Plataforma de Gestão de Clínica e Agendamentos

Este projeto foi desenvolvido como um desafio de programação para consolidação de conceitos de **Programação Orientada a Objetos (POO)** e gerenciamento de dependências
em ambiente acadêmico. O sistema gerencia o fluxo de uma clínica multidisciplinar, controlando cadastros, agendamentos simultâneos, detecção de conflitos de horários e faturamento analítico com emissão de recibos.

---

## 🚀 Como Executar o Projeto

O projeto utiliza o gerenciador de automação **Gradle**. Siga os passos abaixo para clonar, compilar e rodar a aplicação em sua máquina:

### Pró-requisitos
* Ter o **Java JDK 17** (ou superior) instalado.
* Ter o **Git** instalado (opcional, para clonagem).

### 1. Clonar o Repositório
Abra o seu terminal ou prompt de comando e digite:
